# SICAS (Sistema Central de Acessos e Serviços) Frontend
 
Aplicação web Angular do projeto SICAS, desenvolvida para o Hackaton CAIXA pela equipe **404 Team Not Found**.
 
O frontend é responsável por fornecer a interface do usuário, consumindo as APIs REST disponibilizadas pelo backend.
 
---
 
## 🎯 Visão
 
O SICAS propõe centralizar a jornada de trabalho do usuário em um único ambiente digital, reduzindo a necessidade de navegação entre múltiplos sistemas e melhorando a produtividade.
 
Este frontend materializa essa proposta através de uma interface unificada, intuitiva e personalizada.
 
---
 
## 📊 Composição do Projeto
 
- CSS: 43.6% 
- TypeScript: 36.8% 
- HTML: 19.6%
 
---
 
## 🚀 Escalonamento e Evolução
 
O frontend foi estruturado para permitir crescimento contínuo, acompanhando a evolução do backend e das necessidades operacionais da solução.
 
### 🎨 Escalonamento de Interface e UX
 
- estrutura modular de componentes Angular;
- possibilidade de criação de novos módulos sem impacto global;
- evolução da experiência do usuário (UX) com melhorias incrementais;
- organização baseada em componentes reutilizáveis;
- suporte à criação de layouts dinâmicos e personalizados.
 
---
 
### 📈 Escalonamento Funcional
 
- expansão do portal com novos serviços e funcionalidades;
- evolução da busca orientada;
- integração com novos módulos (processos, cotações, normativos);
- crescimento progressivo das funcionalidades de personalização;
- adaptação da interface para novos fluxos operacionais.
 
---
 
### 👤 Escalonamento de Usuários
 
- personalização por usuário;
- exibição dinâmica com base em preferências;
- adaptação da UI para diferentes perfis;
- evolução futura para controle de acesso por perfil (RBAC) integrado ao backend.
 
---
 
### 🔗 Integração com Backend
 
- desacoplamento via consumo de APIs REST;
- compatível com evolução do backend para microsserviços;
- suporte a expansão de endpoints sem alteração estrutural no frontend;
- preparado para consumo de APIs consolidadas (portal unificado).
 
---
 
### ⚙️ Escalonamento Técnico
 
- compatível com builds de produção otimizados;
- possibilidade de deploy em CDN ou infraestrutura corporativa;
- suporte a estratégias de cache e lazy loading;
- viabilidade de divisão em módulos independentes;
- compatível com containerização.
 
---
 
### 📌 Visão de Crescimento
 
O frontend evolui naturalmente para um **portal corporativo centralizado**, servindo como ponto único de acesso para sistemas, processos e informações do usuário.
 
Essa abordagem melhora a experiência, reduz atrito operacional e padroniza a navegação.

## 🔧 Como rodar o projeto
 
No terminal:
 
```bash
# 1. Clonar o repositório
git clone https://github.com/CAIXASANDBOX/hackathon-frontend-hackaton-frontend-404notfound
 
# 2. Entrar na pasta do projeto
cd Hackaton-404-team-not-found
 
# 3. Instalar as dependências
npm install
 
# 4. Rodar o servidor de desenvolvimento
npm start
